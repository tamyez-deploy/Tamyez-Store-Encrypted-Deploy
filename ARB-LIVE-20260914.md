# ARB payment activation

Baseline e292a1f (customer OTP already enabled and confirmed by owner).
Only server.js and server/providerOperations.js changed in runtime.

- ARB_PAYMENTS_ENABLED=true independently enables hosted initiation, inquiry and bank callback.
- STAGING_SAFE_MODE stays enabled for suppliers, general notifications and manual finalization.
- Internal supplier purchase calls fail closed and mark fulfillment for manual review.
- Internal external notifications are skipped while global safe mode remains enabled.
- Missing callback amount is rejected; redirect origin must match the configured bank host.
- PUBLIC_BASE_URL=https://tamyz.store; callback /api/functions/arbResponse.
- Production credentials are stored only in CranL environment, not in this repository.
- 19 offline tests pass: amount/currency/reference integrity, forged callback, duplicate inventory,
  unauthorized request, supplier isolation and existing OTP flows. No bank transaction was sent.
- UI assets, schema, historical data and package dependencies unchanged.

Rollback: ARB_PAYMENTS_ENABLED=false and reapply environment, or deploy e292a1f.
Live payment success still needs the owner's controlled checkout; enabling configuration is not
evidence of an end-to-end bank approval or successful settlement.
